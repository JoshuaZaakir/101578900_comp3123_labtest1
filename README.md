## About This Lab Test

This lab test covers ES6 features, JavaScript promises, and working with files using Node.js.

## Question 1 - ES6 Features

## Question 2 - Promises

Created two functions, resolvedPromise and rejectedPromise. One resolves a message and the other rejects an error.

## Question 3 - File Module

Used the fs and path modules in Node.js to create and remove log files.

- add.js creates a Logs folder and generates 10 text files.
- remove.js deletes the log files and removes the Logs folder.
